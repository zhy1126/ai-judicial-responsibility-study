# 法官陈述：两案 × 四种 AI 参与程度

2026-09-23 已接入研究者提供的两份案件录音和四段参与程度补录，共八份完整音频。无 AI、程序性、实质性、决定性参与分别对应第一人称开场说明；每案开场后的原录音和正文保持一致。所有条件保留页面顶部提示，开场文字用对应颜色突出显示。

## 录音与文字

- `study-narration.js` 是文字来源。`paragraphsFor(caseType, condition)` 返回参与程度开场和案件正文。
- `audio/condition-scripts/` 是八份与网页一致的完整配音稿。
- `audio/shared-scripts/` 仅保留原两份案件正文；不再作为完整实验录音稿。
- `audio/recordings/` 是八份实际部署的 MP3。
- `audio-config.js` 按案件和条件配置文件地址、时长及段落时间点。
- 当前材料版本：`condition-narration-2026-09-23-v1`。

正文仍按研究者提供的 0916 版 Word 分段。补录开场后增加 0.5 秒静音，再接原案件录音。原声不调速、不改音高、不加音乐；四个开场在原补录的静音间隙剪切。原始文件路径不进入公开配置，来源文件名、哈希与制作参数见 `audio-production-0923.json`。

## 播放行为

两案四条件全部配置完整、同源且版本匹配后，统一显示录音。2026-09-25 起默认 1.5 倍速，可选 1 或 1.25 倍，并保持音高；暂停、重播、刷新续播保留所选速度。

文字与播放独立：进入此页后在前台约 15 秒内展开全文，读至末尾、勾选确认即可继续，不要求播放或听完音频。暂停录音不会暂停文字；重播不会清空已读进度。跳转页面时暂停音频。失败时仍能按同样规则完成文字阅读。

历史段落时间配置仍保留，但不再驱动文字揭示。呈现版本为 `independent-reading-audio-2026-09-25-v1`；记录 `condition_audio_fast_text`、前台阅读时长及音频实际开始／完成状态、进度和播放速度，不能把阅读完成误作完整收听。

材料升级会要求尚未完成本案的参与者重新阅读，并清空本案尚未提交的评价。既有已提交答卷保留原材料版本；分析时应区分旧版文字呈现和新版含音频呈现。第二个案件使用同一参与程度、该案件对应的录音。

## 重建与校验

需要本机 `ffmpeg`、`ffprobe`、Python 3、Node.js。运行：

```
python3 scripts/assemble-condition-audio.py 开场补录.mp3 故意伤害原录音.mp3 侵犯著作权原录音.mp3
node scripts/export-condition-transcripts.cjs
node --test tests/condition-audio.test.cjs
node scripts/build.mjs
```

剪切位置和段落时间点仅适用于此次三份原录音。替换录音或修改正文后，必须重新校准时间点并提升材料版本，不能沿用旧时间点。发布前核对全部八个文件的案件、开场条件、文字、播放与完成门槛。

角色引导视频与开放题语音输入是独立功能，不受此次配音接入影响。网站不需要配音 API 或 TOKEN。
