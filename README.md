# 人机协同裁判司法责任研究

供研究合作者审阅的交互调查原型，对应以下研究设计：

- 背景群体：律师、诉讼当事人与普通公众；
- AI 参与方式：无 AI、程序性、实质性与决定性参与；
- 任务类型：自然犯与依赖特定监管规范的法定犯。

## 在线访问

- GitHub Pages（启用后）：https://zhy1126.github.io/ai-judicial-responsibility-study/
- 当前备用站点：https://ai-judicial-responsibility-study.crimemap1126.chatgpt.site

## 本地查看

直接打开 `index.html`。研究者设计台是默认首页，参与者预览也可以使用：

```text
index.html?view=participant&preview=1&role=public&condition=procedural&case=natural
```

## 数据与用途说明

这是供协作审阅和预测试使用的研究原型，不应直接用于正式收集。当前参与者回答只保存在其浏览器 `localStorage` 中，不会上传到 GitHub 或其他服务器。

案件、法院和当事人均为虚构。网页设置为不主动被搜索引擎收录，但公开仓库及持有链接的访问者仍可查看源代码和页面内容。

## GitHub Pages

仓库已包含 `.github/workflows/pages.yml`。创建仓库并上传文件后，请在仓库的 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**；以后每次推送到 `main` 都会自动部署。
